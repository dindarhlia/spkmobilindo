# Used Car Selection Decision Support System — SPK Mobilindo
A web-based Decision Support System (DSS) developed as a final year project to support used car selection at Sadulur Mobilindo using the MOORA (Multi-Objective Optimization on the Basis of Ratio Analysis) method.

## Project Overview
This system helps users compare used car alternatives and generate recommendations based on selected criteria and their respective weights.

## Key Features
* Used car catalog and alternative management
* Evaluation of 20 used car alternatives
* Assessment based on seven criteria:
Price, Engine condition, Body condition, Production year, Mileage, Vehicle tax, Document completeness
* MOORA-based ranking and recommendation results
* Static weighting for showroom-based rankings
* Dynamic weighting to accommodate customer preferences

## Technologies Used
* PHP Native
* MySQL
* Bootstrap
* HTML, CSS, and JavaScript
* MOORA decision-making method

## Project Purpose
The project was developed to demonstrate the application of a multi-criteria decision-making method in a web-based used car recommendation system.
